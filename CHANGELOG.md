# Changelog

Notable user-facing changes to this project will be documented here.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and intends to follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) once its public API is stable. During
the `0.x` period, minor releases may contain breaking API or world-format changes; these must be
called out under **Changed** or **Removed** with migration guidance.

Contributors add entries to **Unreleased** for user-visible changes. Use the **Added**, **Changed**,
**Deprecated**, **Removed**, **Fixed**, and **Security** headings as applicable. Maintainers move
entries into a dated release section and add comparison links when cutting a release. Internal
refactors, formatting-only changes, and test-only changes do not require entries unless they affect
contributors.
