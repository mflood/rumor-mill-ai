# Support

Rumor Mill AI is maintained by volunteers and has no guaranteed response time.

- For setup and usage questions, start with the [README](README.md) and documentation under
  `docs/`, then open a GitHub Discussion if available.
- For reproducible bugs or focused feature proposals, use the matching GitHub issue template.
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not disclose them publicly.
- For conduct reports, use the private address in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Include the project version or commit, operating system, Python version, relevant configuration
with secrets removed, reproduction steps, and sanitized logs. Please do not post API keys,
personal data, private conversations, proprietary world content, or confidential model prompts.
